# সপ্তদশ সহযাত্রা — সঞ্চয় ও সদস্য ব্যবস্থাপনা সিস্টেম

একটি আধুনিক, নিরাপদ এবং প্রিমিয়াম ডিজিটাল সঞ্চয় ও সদস্য ব্যবস্থাপনা ওয়েব অ্যাপ্লিকেশন। সমিতির সকল সদস্যের কিস্তি হিসাব, বিলম্ব জরিমানা, আজীবন লেজার স্টেটমেন্ট এবং আধুনিক ল্যানিয়ার্ড-স্টাইল লম্বাটে আইডি কার্ড তৈরি ও পিডিএফ ডাউনলোডের সুবিধাসম্পন্ন।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **লম্বাটে (Portrait) ল্যানিয়ার্ড আইডি কার্ড**: ৫৪ মিমি × ৮৬ মিমি আধুনিক ডিজাইনের আইডি কার্ড, যা সরাসরি হাই-রেজোলিউশন PDF এবং PNG ছবি আকারে ডাউনলোড করা যায়।
- **মাস্টার ডেটাশীট এক্সপোর্ট (Bulk PDF)**: সকল সদস্যের ছবি, যোগাযোগ, কিস্তির হার, মোট সঞ্চয় ও বকেয়াসহ এক ক্লিকে সম্পূর্ণ ডিরেক্টরি A4 সাইজ PDF ডাউনলোড।
- **আজীবন স্মার্ট লেজার**: ২০২৬ সালের শুরু থেকে প্রতি মাসের কিস্তি, বিলম্ব জরিমানা এবং আংশিক জমার স্বয়ংক্রিয় হিসাব।
- **অ্যাডমিন সিস্টেম কাস্টমাইজেশন**:
  - সমিতির নাম ও স্লোগান পরিবর্তন
  - কাস্টম লোগো ছবি আপলোড
  - ৫টি ভিন্ন প্রিমিয়াম থিম নির্বাচন (Teal, Emerald, Navy, Indigo, Gold)
  - ডিফল্ট কিস্তির হার ও শেষ তারিখ নির্ধারণ
- **বকেয়া নোটিফিকেশন**: এক ক্লিকে সদস্যদের হোয়াটসঅ্যাপে (WhatsApp) স্বয়ংক্রিয় বাংলা নোটিফিকেশন মেসেজ পাঠানোর সুবিধা।
- **ভূমিকা-ভিত্তিক অ্যাক্সেস (RBAC)**: অ্যাডমিন (সম্পূর্ণ নিয়ন্ত্রণ) এবং মেম্বার/অপারেটর (রিড-অনলি) অ্যাকাউন্ট।

---

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite
- **Database & Auth**: Firebase Firestore & Firebase Auth
- **PDF & Canvas**: jsPDF, html2canvas
- **Icons**: Lucide React

---

## 🚀 লোকাল মেশিনে চালানোর নিয়মাবলী (Local Setup)

```bash
# ১. ডিপেনডেন্সি ইনস্টল করুন
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে `http://localhost:3000` লিংকে প্রবেশ করুন।
